# 能力扩展：提示词模板、AI 应用目录与技能文件上传

本次扩展补齐了前三项“部分支持”的能力，保持原有登录、班级隔离、检索、流式与 MCP 主路径不变。

## 1. 提示词模板

### 数据与接口

- 表 `prompt_templates`：`class_id`、`name`（班内唯一）、`description`、`content`、`seed_key`。
- 教师接口：
  - `GET/POST /api/prompt-templates`
  - `GET/PUT/DELETE /api/prompt-templates/{id}`
  - `GET /api/prompt-variables`
  - `POST /api/prompt-templates/{id}/preview`
- 智能体新增 `prompt_template_id`；创建/更新智能体时可绑定模板。模板被删除时，外键置空，智能体回退到自身 `prompt`。

### 变量

只允许以下可信变量：

| 变量 | 含义 |
|---|---|
| `{{class_name}}` | 当前班级名称 |
| `{{agent_name}}` | 当前智能体名称 |
| `{{student_name}}` | 当前使用者显示名 |
| `{{skill_name}}` | 本次命中的技能名，未命中为空 |
| `{{subject}}` | 技能的资料范围 |
| `{{date}}` | 回答当天日期 |
| `{{materials}}` | 智能体绑定材料标题，顿号连接 |

**学生提问不作为模板变量**。它仍只进入用户消息，避免把不可信文本提升为系统指令。未知变量、`{{question}}`、大小写变体或残缺 `{{` 在保存时返回 400。

### 运行

一次回答开始时，若智能体绑定了模板，服务端用当前班级、智能体、使用者、技能、日期与材料标题渲染模板，作为系统消息第一段；渲染结果为空或模板不存在时回退到 `prompt`。模板正文同样经过“资料是数据不是指令”的边界句。

## 2. AI 应用目录

### 数据与接口

- 表 `ai_apps`：名称、说明、分类、图标、提示词模板、默认提示词、默认技能 ID 列表、默认材料 ID 列表、启用状态。
- `agents` 新增 `app_id`，记录智能体由哪个应用实例化而来；应用删除时置空，不删除智能体。
- 接口：
  - `GET /api/apps`、`GET /api/apps/{id}`（登录即可；学生只看到已启用）
  - `POST/PUT/DELETE /api/apps[/{id}]`（教师）
  - `POST /api/apps/{id}/instantiate`（教师，`{name?}`）→ 201 智能体

### 内置应用

种子数据为班级 A 创建：

- 数学解题应用（📐，绑定数学技能与数学材料）
- 语文解题应用（📖，绑定语文技能与语文材料）
- 通用学科问答（🧭，不绑定技能，覆盖两本材料）

班级 B 创建“通用学科问答”（绑定 B 班物理材料）。种子智能体“数学解题助手”“语文解题助手”已关联对应应用。

### 实例化语义

- 默认助手名称为 `<应用名>助手`；班内重名返回 400，前端允许改名重试。
- 实例化复制应用默认的模板、提示词、技能与材料；此后智能体与应用独立演进。
- 应用删除只解除 `agents.app_id` 关联，已有会话与智能体继续可用。
- 停用应用不会出现在学生列表，教师也不能从停用应用创建助手。

## 3. 技能文件上传

- `POST /api/skills/upload`：multipart `file`，仅 `.md/.txt`，≤64KB，UTF-8，教师专属。
- `PUT /api/skills/{id}/upload`：替换现有技能。
- 解析、字段/长度校验、工具引用校验与 JSON 创建路径完全一致；重名返回 400。
- 前端技能页提供“上传技能文件”直接上传；编辑弹窗另提供“从文件载入内容”，先把文件读入文本框，便于预览修改后再保存。

## 安全与隔离

- 模板、应用、技能均按班级划分；跨班按编号访问统一 404，学生写接口 403。
- 模板只允许可信上下文变量，学生问题不进入系统消息。
- 应用实例化只接受本班模板、技能与材料；缺失时拒绝创建。
- 技能文件大小、扩展名、UTF-8 与解析错误均返回可读 400；不落盘为可执行资源。
- 原有 JWT、班级过滤、引用、MCP 令牌与审计逻辑未改变。
